# Demo Files

All demo files are single-level and can be opened directly in VSCode.

## Start Here (Parser-Compatible)

- `quickstart_linear_gentzen.mypa`: minimal interactive linear Gentzen demo (`rlolli`, `rtensor`, `rwith`).
- `showcase_all_features.mypa`: compact cross-system showcase (LL/LL!/NJp/NKp/System F).

## Interesting (Parser-Compatible)

- `showcase_linear_from_lean.mypa`: richer linear proofs ported from Lean examples.
- `showcase_proof_systems.mypa`: side-by-side examples across supported proof systems.
- `problemset_zadlitt_1_positive.mypa`: concise NJp exercise set.
- `problemset_ipc_foundations.lean`: small foundational IPC exercises as Lean derivations/countermodel formulas.
- `problemset_zadlitt_1_negative.lean`: Lean Kripke countermodels for negative Zadlitt Problem 1 items.
- `problemset_zadlitt_2_3_negative.lean`: Lean countermodel-based non-derivability example.
- `kripke_tactic_countermodel_demo.lean`: stable `KripkeTactic` compatibility demo (`finish_unprovable_using`).

## Reference / Smoke

- `smoke_linear_gentzen.mypa`: tiny smoke check.
- `showcase_natural_deduction_from_lean.mypa`: one ND translation from Lean.
- `reference_problemset_zadlitt_2_3_positive.mypa`: larger NJp file kept for reading/reference; not fully supported by the current MyPA parser.
